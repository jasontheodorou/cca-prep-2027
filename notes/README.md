# Study notes

Written on the site's Study tab. Each note is one Markdown file named after when it was started (`2026-10-22-1432-x7k2.md`), with a short header:

```
---
id: 2026-10-22-1432-x7k2
title: "Lesson 1.1 Agentic Loops"
created: 2026-10-22T13:32:10.000Z
updated: 2026-10-22T13:40:02.000Z
tags: [1.1, 1.5]
---
```

`tags` are the exam task statements the note covers, worked out from its words (`src/lib/tags.ts`). Pasted screenshots are in `images/`. A YouTube video is written as `![video](its address)`.

The local server saves each change straight away and commits this folder a minute after the last change, with the message "Study notes: autosave". It never pushes.
