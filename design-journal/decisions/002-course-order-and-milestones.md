# 002 Course order, units and milestones

## Context

The brief asked for DiSSS (small units, prioritisation, sequence) without it becoming UI, with the official exam materials as the only authority, and progress based on explicit milestones.

## Decision

- Source: exam guide v1.0 (July 2026). A subagent compared it with v0.1 (February 2026): the 30 task statements, all their bullets and the 4 exercises are identical. v1.0 adds exam details (60 items, multiple-response items, 120 minutes) and removes the practice-exam recommendation, so the course has no practice-exam step.
- Deconstruction: one unit per task statement, closed to one plain line until opened.
- Selection: each line of "Knowledge of" and "Skills in" is kept, condensed into plain English, one line for one line.
- Sequence: Domain 3 (Claude Code, familiar from daily use), then 1, 2, 4, 5, then the four exercises.
- Milestones: each "Skills in" line (and each exercise step), 147 in all. Ids such as `1.1.2` are stable and must never be renumbered.

## Consequences

Progress percentages measure ticked skills only. Logging time ticks nothing.
